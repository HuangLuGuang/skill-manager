# P1 补强：可读 Agent 行为审计验收

日期：2026-09-24。范围：当前 macOS、独立 Agent 任务、loopback 隔离平台及实际浏览器页面；未提交、推送或部署。沿用设备认证、AIDR scopes 和现有设备访问权限。

## 交付契约

新事件 schema 2 携带 behavior.version=1：工具原名、操作分类、白名单命令/工作目录/明确目标、结果状态、明确退出码、结果依据、来源字段、提取方式、脱敏/截断及不确定性。页面用固定中英文模板生成操作说明，不调用 LLM。

- actions 最多 4 个；每项 command 最多 1536 UTF-8 字节，cwd 和每个目标最多 512 字节，目标最多 4 个、来源字段最多 8 个；结果依据和不确定性各最多 8 项。
- 参数白名单：command/cmd、workdir/cwd、file_path/path、old_path/new_path、url；apply_patch 仅提取补丁文件头。Claude 记录 cwd 仅在明确存在时补充。未知参数、description、Prompt、文件正文和完整结果不复制。
- 本地写 SQLite/outbox 前遮蔽秘密键值、Authorization/Cookie、常见 Token/私钥、URL 认证/查询串。命令中的 heredoc 和非路径引号正文保守遮蔽，可能降低脚本可读性。服务端再次拒绝未知字段、超限或未脱敏秘密模式。规则不等于识别任意无标签字符串中的秘密，不能以此声明通用 DLP。
- 状态分开表示：明确退出码 0、日志错误、无错误标记、取消/中断、结果未知、缺少调用/结果、冲突。没有结果不显示运行中。多个退出码不合成单一结果。两个日志时间相减标为“日志时间差”，不是系统执行耗时。
- 操作身份包含设备、Agent、来源、会话、回合和 call。Codex 游标可选保存 16 个调用回合映射；结果迟到使用已记录回合，映射缺失或有歧义保持未配对。每操作最多保留 16 个证据 ID，超过上限或内容冲突明确标记。
- 所有结果是 **Agent 日志证据**，process_relation 保持 unknown。shell 命令出现路径不会生成文件/网络系统事实；exec/js 的静态字面量子调用保留包装层级，不证明分支执行或每个子操作成功。

本节独立于前面的显式文件/隔离平台验收。使用本机 backend 8001、默认 Claude/Codex 日志根、原设备 amc_911abfcfe720cc52f3c4ffe6 与原状态目录；没有传 --codex-file。先核对原进程归属、备份 SQLite、停止原显式文件采集器，再原地升级。未修改业务文件，未提交、推送、部署或安装服务。

### 根因及改动

旧 worker 每次调用无状态 Discover，最多取 64 个来源，随后覆盖读取列表；再次扫描从头开始，尾部来源可能一直没有读取机会。现有精确游标、显式文件读取、结构化 exit_code 和 input_text 结果适配本来可用，没有重复重写这些功能。

新增持久化目录前沿及来源目录表；枚举预算耗尽后继续，已知来源独立轮转探测，近期活动与历史积压各有读取预算。240 个历史文件的测试对 Claude/Codex 分别运行，包含扫描中重启、新文件、旧日期追加、轮转、同大小同 mtime 替换、容量/跳过原因持久化。另有 200 个自动发现来源的 worker 集成测试，预期 800 条逻辑事件，覆盖 503 重试、冻结批次及重启后排空。文件数/目录数/扫描时间/解析工作均有上限。

真实扩展到全部来源时额外暴露：
- SQLite 返回 table locked；旧路径在每个来源后强制 WAL 截断，并以很短的调度 deadline 取消包含 SQLite 事务的 Collect。现已使用解析器自己的协作预算，事务不随调度片结束而取消；保留清理按分钟执行，WAL 依配置自动 checkpoint、退出时截断。锁错误的具体触发点未从原日志独立证明，不能把上述风险消除当作长期稳定性保证。
- 已脱敏命令中引号边界变化，生成投影再次校验失败。用真实失效投影复现，改为最多 8 次归一化至稳定结果；仍不稳定时仅保留 [REDACTED COMMAND]。补充幂等及服务端白名单回归。
- 升级联调时发现游标新字段未在上传校验模型声明，导致请求被拒。已补齐可选字段，旧输入缺省不补进持久化投影，保持旧覆盖摘要。原冻结批次原样重试成功，未删队列。
