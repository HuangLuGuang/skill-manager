# 国际化与语言支持

Agent Manager 的中文名称为“AI智能体全生命周期管理平台”，英文名称固定为
“Agent Manager”。管理平台、桌面客户端、Skill 扫描器和 Agent Skill
Verifier 支持简体中文与英文。

## 用户使用

- 管理平台和桌面客户端首次启动时跟随浏览器或操作系统语言。
- 用户选择语言后会保存在本地；已登录的平台用户还会同步账号语言偏好。
- Skill 扫描器使用 `AGENT_MANAGER_SCANNER_LANG=zh-CN|en-US`。
- Agent Skill Verifier 使用 `AGENT_MANAGER_VERIFIER_LANG=zh-CN|en-US`。
- API 客户端通过 `Accept-Language: zh-CN` 或 `Accept-Language: en-US`
  获取本地化错误说明。

文件内容、用户输入、Skill 原文、代码、命令输出和第三方证据保持原文，
不会因为界面语言改变而被翻译。

## 开发约定

- 管理平台的新文案使用语义化 i18n Key；`legacy.*` 仅承载已迁移页面。
- 桌面客户端动态文案使用稳定 `ui.*` Key 或 `tf` 模板。
- 状态、风险、审计事件、客户端任务统一在领域语言目录中维护。
- 业务逻辑只判断稳定状态或错误码，不判断中文或英文提示。
- API 错误结构统一为：

```json
{
  "detail": "Localized message",
  "error_code": "skill.not_found",
  "error_params": {}
}
```

## 验证命令

```bash
cd web
npm run test:i18n
npm run build

cd ../client/desktop
npm run test:i18n
npm run test:release

cd ../../
uv run --project backend --with pytest pytest tests/test_i18n_api.py -q
```

平台检查会校验中英文键一致性、旧页面稳定键、伪语言扩展效果、未翻译的
界面文本和 DOM 翻译扫描；桌面检查会校验静态文案、动态模板和系统通知。
