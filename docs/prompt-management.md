# 历史说明：独立 Prompt Registry

独立上传、审核、签名 Prompt 的管理台入口已经不作为当前推荐流程。

当前产品主线是把 Prompt 风险治理放到模型网关运行时链路中：

1. 在 `模型网关` 配置供应商、模型、组策略绑定和隐私策略。
2. 在 `智能体管理 / 统一凭证中心` 创建 `模型调用凭证`。
3. 在凭证上开启 Prompt 防护模式：
   - `仅记录`：灰度观察，不影响请求。
   - `告警放行`：记录风险并放行，适合演示和调优。
   - `高风险阻断`：命中高风险提示词注入、系统提示词泄露或凭据外传时阻断。
4. 外部 Agent 或应用使用该凭证调用 OpenAI-compatible 模型网关。
5. 在 `模型网关 / 隐私审计` 和 `隐私链路追踪` 查看命中规则、风险等级、处理动作、脱敏、压缩和模型响应。

这样不要求用户额外上传 Prompt 模板，也不会把 Prompt 治理拆成另一套生命周期。详细说明见 [model-gateway.md](model-gateway.md)。
