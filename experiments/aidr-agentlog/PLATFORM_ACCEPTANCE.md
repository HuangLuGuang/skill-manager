## 范围与实现

- P1-01 读取器与 P1-02 本地事务、崩溃恢复、保留和容量证据分别见 [读取验收](ACCEPTANCE.md)、[本地持久化验收](STORE_ACCEPTANCE.md)。

- `aidr-sync` 明确启动读取、SQLite 落库、HTTP 上传与心跳。每轮摄入预算 2 秒，默认间隔 2 秒；每轮最多上传 4 批，每批 500 条 / 1 MiB。回执校验通过后才删除 outbox。

## 受控断网与吞吐

`p1_server.py` 使用生产 auth、clients、AIDR 路由及隔离 SQLite；只有验证码生成和无关品牌返回是测试 fixture。`p1_network_proxy.py` 在标记存在期间实际关闭上传 TCP 连接，不改变主机网络或管理员 relay。`verify_p1_transport.py` 启动真实 Go CLI，持续读取文件、落库、重试，再恢复连接。

## 验收中发现并修复

1. API 拦截器已返回 response.data，面板再次访问 `.data` 导致状态读取失败；按现有 API 契约修正并实机复查。
2. 本次观察中，取消上下文后 SQLite 事务可能返回 `sql.ErrTxDone`；worker 按真实读取期限/父 context 区分预算耗尽和退出，CLI 在已取消上下文下正常结束并输出状态。重启运行 5 秒返回 0、队列清空，写锁可重新取得。
3. 多来源相同 Agent 版本的能力心跳去重，保留较差状态；显式单文件不存在时发现状态标为 unavailable。
4. 离线界面增加“统计与能力来自最后一次心跳”的中英文说明，避免将过时计数作为实时状态。
